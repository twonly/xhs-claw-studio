# 红薯采集器试用说明

这是一款用于抓取和分析小红书笔记数据的 Chrome 插件，当前适合朋友体验的核心能力包括：

- 批量抓取小红书个人主页下的笔记
- 导出标题、正文、标签、互动数据
- 进入分析看板查看博主分析、多博主对比、素材库
- 导入创作者后台数据，做更深层的个人账号分析
- 配置你自己的兼容 API Key 后使用 AI 报告

## 1. 安装方式

当前试用版推荐使用“加载已解压的扩展程序”安装：

1. 解压我发给你的插件压缩包。
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的插件目录。

注意：Chrome 这里选择的是文件夹，不是 ZIP 文件本身。

安装完成后，浏览器右上角会出现插件图标。

## 2. 支持哪些页面

当前支持以下 3 类页面：

- 小红书个人主页
- 小红书笔记详情页
- 小红书创作者中心数据页

如果打开插件时提示“不支持当前页面”，请先打开以上页面之一，再点击插件。

## 3. 最推荐的试用路径

第一次体验，建议按这个顺序：

1. 打开一个小红书个人主页。
2. 点击插件，选择批量抓取。
3. 抓取完成后，点击“数据分析”进入分析看板。
4. 在分析看板里先看：
   - 博主详情分析
   - 多博主对比
   - 素材库
5. 如果你有创作者后台导出的 Excel，可以继续导入，体验个人分析。

插件内已经加了首次引导，第一次进入分析页和素材库时会自动提示关键入口。

## 4. AI 功能说明

AI 功能默认不代付模型费用。

如果你要使用 AI 报告，需要在插件设置中填写你自己的兼容 API Key。当前支持多家模型厂商，并支持自定义模型名称。

说明：

- 不填 API Key，不影响抓取、导出、分析看板、素材库等基础功能。
- 填了 API Key 后，AI 报告和相关问答能力才会生效。

## 5. 隐私与数据说明

这次发给你的插件包本身，不会包含我本地浏览器里保存的内容。

也就是说，下面这些不会跟着 ZIP 一起发出去：

- 我的 API Key
- 我本地保存的博主数据
- 我本地的 AI 缓存报告
- 我本地的个人偏好设置

原因是这些数据保存在浏览器本地的 `chrome.storage.local` 中，不在插件源码文件里。

## 6. 你可能会遇到的情况

### 6.1 图片封面偶尔加载失败

小红书图片链路偶尔会有防盗链或失效问题。

现在即使封面没显示，也不会影响：

- 查看标题
- 查看互动数据
- 打开详情
- 做筛选和导出

### 6.2 批量抓取中断

如果小红书触发风控、验证码或页面刷新，抓取可能暂停。重新打开插件后，通常可以继续。

### 6.3 创作者后台导入后没有数据

请确认导入的是小红书创作者中心导出的 Excel 文件，并且当前导入对象和分析的博主是同一个账号。

## 7. 体验时重点帮我看什么

如果你愿意，重点帮我关注这几类反馈：

- 第一次打开时，是否知道下一步该点哪里
- 抓取流程是否清楚，是否会卡住
- 分析看板里哪些模块最有用，哪些看不懂
- 素材库是否足够适合找选题和拆竞品
- AI 配置和使用门槛是否过高
- 哪些地方像“工具”，哪些地方已经接近“产品”

## 8. 常见问题

### 8.1 会不会自动扣模型费用？

不会。只有你自己填入兼容 API Key 后，AI 请求才会走你的模型账户。

### 8.2 我不想用 AI，只想导出和分析，可以吗？

可以。大部分核心功能都不依赖 AI。

### 8.3 这是商店版吗？

不是，这是一份朋友体验版，需要通过“加载已解压的扩展程序”安装。
