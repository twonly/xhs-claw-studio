INSTALL GUIDE

安装后，不用学一堆东西，直接开始导出。

这就是一个实用工具，不是重产品培训。流程越短越好，越快得到结果越好。

  1. 安装扩展后，打开小红书网页，进入目标主页或笔记详情页。
  2. 点击扩展图标，选择单篇或批量模式，并设置抓取数量和延时。
  3. 开始导出，得到标题、正文、标签、图片、评论和互动数据。
  4. 需要时再继续查看看板、导出 CSV / JSON，或进入素材库检索。

FAQ

把价格敏感用户最关心的问题先回答清楚。

红薯采集器适合谁？

适合小红书运营、竞品研究者、内容团队，以及只想把账号内容导出来做备份和复盘的人。

为什么说它是平替？

因为很多人真正想要的只是导出和轻量复盘，不需要一整套又贵又复杂的平台。红薯采集器就是把这件事做得更轻、更直接。

导出的数据包含哪些字段？

包括标题、正文、标签、图片链接、点赞、收藏、评论、发布时间、原文链接及评论内容等。

是不是只有导出，没有分析？

不是。它会保留基础分析看板和素材库能力，但不会把首页讲成一个复杂的大平台。

数据会不会默认上传到云端？

默认以本地处理为主。云同步属于可选能力，需要用户主动登录或启用，详见隐私政策。

可以。当前页面已经补充了产品说明、安装说明、FAQ、隐私政策入口，以及基础 SEO 文件。
