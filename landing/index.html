WHY IT MATTERS

它解决的不是“导出文件”问题，而是“内容资产化”问题。

把零散网页信息变成你自己的结构化数据库，后续复盘、研究、筛选、汇报和素材沉淀都会更快。

运营复盘

直接查看高互动内容、标签策略、发布时间规律和标题模式，减少人工整理成本。

竞品研究

批量导出同赛道账号样本，统一分析正文、标签、互动和爆款特征。

素材沉淀

把正文、图片、评论与链接沉淀成可检索素材库，方便长期选题和内容参考。

创作者后台复盘

可导入创作者后台导出的 Excel，把曝光、观看、涨粉、分享等指标并到同一份分析里。

FEATURES

从抓取到洞察，整条链路都围绕“导出后还能继续分析”来设计。

所有信息只服务于一个目标：把小红书公开内容提取成结构化、可分析、可复用的数据资产。

01

主页批量抓取

打开任意用户主页，自动收集卡片并逐篇提取详情，而不是只能手动抓单篇。

02

断点续传

长任务中断后可以继续，已抓到的数据不会丢，适合几十篇到上百篇任务。

03

智能防封节奏

支持随机延时和分段冷却，更贴近真实浏览节奏，降低人工盯任务的压力。

04

分析看板

导出后继续进入概览指标、Top Notes、标签词频、内容洞察和深度分析视图。

05

多博主对比

把多个账号拉到同一个对比页，统一看评分、标签差异、互动分布和 AI 对标建议。

06

AI 深度报告

基于聚合后的结构化数据生成账号定位、爆款公式、选题建议与对标结论。

07

创作者数据导入

导入创作者后台 Excel 后，可以补充曝光、观看、封面点击率、涨粉、分享等后台指标。

08

云同步

本地数据可按需同步到 Supabase，适合换电脑、换浏览器或跨设备延续研究流程。

09

素材库与导出

支持全文搜索、多维筛选、复制，以及 CSV / JSON / PDF 等输出方式。

10

BYOK 多厂商 AI

支持 DeepSeek、OpenAI、Moonshot、智谱、通义千问、SiliconFlow 等厂商，并允许手填自定义模型名。

INSTALL GUIDE

作为商店配套官网，这里直接告诉用户怎么安装、怎么开始。

当前页面可作为 Chrome Web Store 的官网链接、产品说明页和隐私政策入口，也适合直接发给朋友做功能体验说明。

  1. 安装扩展后，打开小红书网页，进入目标主页或笔记详情页。
  2. 点击扩展图标，选择单篇或批量模式，并设置抓取数量、延时和冷却策略。
  3. 抓取完成后，直接进入分析页查看看板、对比和 AI 报告。
  4. 如需更深复盘，可继续导入创作者后台 Excel，或按需开启云同步。

WORKFLOW

3 步完成一次完整的小红书内容研究流程。

不需要脚本部署，不需要额外环境，只需要 Chrome 扩展、目标页面，以及你自己的 AI Key（如果要用 AI）。

1

打开目标账号

进入小红书主页或笔记详情页，点击扩展图标，选择单篇模式或批量模式。

2

运行导出任务

设置抓取数量、延时和冷却策略，扩展自动提取标题、正文、标签、图片与互动数据。

3

进入分析与复用

查看看板、做多博主对比、生成 AI 报告，或者沉淀到素材库里做长期检索和复盘。

FAQ

围绕产品本身，把用户最关心的问题先回答清楚。

这个扩展适合谁？

适合小红书运营、品牌投放、竞品研究、内容团队，以及需要做内容沉淀与素材检索的人。

现在收费吗？

当前阶段以开放使用和收集反馈为主。核心抓取、导出、分析和对比功能都可以直接使用；AI 需要你自己配置兼容 API Key。

导出的数据包含哪些字段？

包括标题、正文、标签、图片链接、点赞、收藏、评论、发布时间、原文链接及评论内容等。

是不是只有导出，没有分析？

不是。红薯采集器的重点之一，就是导出后还能继续进入分析看板、多博主对比、素材库和可选的 AI 流程。

数据会不会默认上传到云端？

默认以本地处理为主。云同步属于可选能力，需要用户主动登录或启用，详见隐私政策。

AI 支持哪些厂商和模型？

当前支持 DeepSeek、OpenAI、Moonshot、智谱、通义千问、SiliconFlow 等兼容接口；提供推荐模型列表，也支持直接手填自定义模型名。

能不能导入创作者后台数据一起分析？

可以。分析页支持导入小红书创作者后台导出的 Excel，把曝光、观看、涨粉、分享等后台指标并进同一个复盘视图。

这个官网可以作为商店官网链接吗？

可以。当前页面已经补充了产品说明、安装说明、FAQ、隐私政策入口，以及基础 SEO 文件。
