HongShu Claw Privacy Policy

Last updated: 2026-04-17

1. Scope

This policy applies to the Chrome extension HongShu Claw and explains how it handles public XiaoHongShu data, local analysis data, and optional cloud sync.

2. Data types the product may process

  • Publicly visible note titles, body text, tags, image links, comments, and engagement metrics from pages the user actively opens.
  • Export results, filters, analysis outputs, and local cache data generated inside the extension.
  • Optional account and sync data when the user explicitly enables cloud sync or AI-related features.

3. What we do not collect by default

  • We do not collect or store the user's XiaoHongShu password.
  • We do not intentionally access unrelated browsing content outside the extension's feature scope.
  • We do not upload local content to the cloud unless the user explicitly enables optional sync features.

4. How data is used

  • To export public XiaoHongShu note content and engagement data.
  • To generate local dashboards, lightweight analysis, filters, and material-library indexes.
  • To support optional AI analysis and optional cloud sync when those features are actively used.
  • To improve export stability, resume behavior, and product usability.

5. Local storage and optional cloud sync

By default, HongShu Claw uses browser-local storage. Exported results, analysis state, and local history are primarily stored inside the local browser environment.

If the user explicitly signs in or enables cloud sync, related data may be uploaded to cloud infrastructure to support multi-device access and persistence.

6. AI features

When the user actively uses AI reports or AI chat, the product may send the required summarized analysis context to the configured AI service provider. This is only done to complete the user-requested task.

7. Third-party services

Certain features may rely on third-party services such as AI APIs, cloud databases, analytics providers, or future payment and licensing systems. Data is only shared with such services when the relevant feature is actively enabled or triggered by the user.

8. Security and user control

We try to follow reasonable technical measures such as local-first defaults, minimum permissions, and opt-in sync behavior. However, no networked or cloud-based service can guarantee absolute security.

Users can control their data footprint by uninstalling the extension, clearing browser storage, removing local data, or disabling optional cloud sync and AI features.

9. Policy updates

If this policy changes, the latest version will be published on this page. Continued use of HongShu Claw means you accept the latest published version.
